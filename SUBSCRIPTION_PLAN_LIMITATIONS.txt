1. EXECUTIVE SUMMARY & ARCHITECTURE OVERVIEW
================================================================================
The subscription system enforces multi-tiered access control and resource quotas 
across Organizations, Sites, Managers, Supervisors, and Construction Drawings.

Every organization workspace operates under one of 5 distinct subscription tiers:
  1. Free Trial  (14-Day evaluation tier)
  2. Silver      (Starter tier for small contractors)
  3. Gold        (Standard fixed-quota tier for growing teams)
  4. Platinum    (Dynamic scale tier with customizable site quotas)
  5. Enterprise  (Unlimited / Dedicated infrastructure tier)

Quotas are strictly validated in real-time before resource creation via 
SubscriptionLimitService and Firestore security rules.

--------------------------------------------------------------------------------
RESOURCE LIMIT DEFINITIONS:
  - Active Sites / Projects : Total count of non-archived construction sites.
  - Total Team Users        : Cumulative limit of (Admin + Managers + Supervisors). Workers are strictly excluded.
  - Managers                : Dedicated project manager accounts.
  - Supervisors             : On-site supervisor accounts.
  - Layout & Drawings       : PDF / image blueprints and technical drawings per site.

4. LAYOUT & DRAWINGS MODULE: RULES & WORKFLOW MATRIX
================================================================================
The Layout & Drawings module tracks blueprints, site maps, and architectural layouts 
per construction site. Usage is tracked in Firestore under 'siteDrawingsUsage/{siteId}'.

Rule Details by Plan:
--------------------------------------------------------------------------------
1. Free Trial:
   - Cap: 1 document per site.
   - Action: Upload allowed once. Viewing allowed.
   - Deletion: Blocked. User is prompted to upgrade.
   - Re-upload: Blocked. User is prompted to upgrade.

2. Silver Plan:
   - Cap: 1 document per site.
   - Action: Upload allowed once. Viewing allowed.
   - Deletion: Blocked.
   - Re-upload: Blocked.

3. Gold Plan:
   - Cap: 1 active document per site.
   - Action: Upload, view, 1 deletion, 1 re-upload.
   - Rule: If a user deletes the active document, usage counter records 1 delete.
     User may then re-upload 1 replacement document. Further deletes are locked.

4. Platinum Plan:
   - Cap: 2 active documents per site (e.g. 1 architectural + 1 structural).
   - Action: Upload up to 2 active documents simultaneously.
   - Deletion: Unlimited.
   - Re-upload: Unlimited.

5. Enterprise Plan:
   - Cap: 2 active documents per site.
   - Action: Upload up to 2 active documents simultaneously.
   - Deletion: Unlimited.
   - Re-upload: Unlimited.

5. RESOURCE ENFORCEMENT & VALIDATION METHODS
================================================================================
The application enforces these rules through SubscriptionLimitService:

1. canCreateSite():
   - Compares active site count in Firestore against limits.maxProjects.
   - Blocks addition when limit reached, displaying modal with plan name and upgrade link.

2. canCreateManager():
   - Step 1: Checks total user count against limits.maxTotalUsers.
   - Step 2: If plan defines maxManagers (e.g. Gold: 5), checks manager count against limits.maxManagers.
   - Blocks addition and prompts upgrade if either condition fails.

3. canCreateSupervisor():
   - Step 1: Checks total user count against limits.maxTotalUsers.
   - Step 2: If plan defines maxSupervisors (e.g. Gold: 10), checks supervisor count against limits.maxSupervisors.
   - Blocks addition and prompts upgrade if either condition fails.

4. canUploadDrawing(siteId, newDocsCount):
   - Validates (activeDocsCount + newDocsCount) <= drawingLimits.maxActiveDocsPerSite.
   - Validates re-upload quotas if totalUploadCount > 0.

5. canDeleteDrawing(siteId):
   - Validates drawingLimits.allowDelete == true.
   - Validates deleteCount < maxDeletesPerSite (for Gold).

6. UPGRADE & DOWNGRADE LIFECYCLE MANAGEMENT
================================================================================
1. Immediate Upgrades:
   - When moving to a higher tier immediately, payment is processed via PayU gateway.
   - On successful payment verification, the active plan document is immediately updated
     and new quotas take effect in real time.

2. Queued Upgrades:
   - If an organization renews or pre-books an upgrade before the current plan expires,
     the new plan is stored as 'queuedPlan' with 'queuedStartDate'.
   - When the current plan end date passes, the background service / login flow 
     automatically promotes the queued plan to active.

3. Plan Expiration:
   - If a subscription reaches its expiry date without renewal, the organization 
     reverts to inactive status.
   - The user is redirected to the Subscription / Pricing page to renew.
   - Data is preserved safely and access is restored immediately upon renewal.
