1. EXECUTIVE SUMMARY & MIGRATION GOALS
====================================================================================================
The goal of this migration is to transition the existing eBricks / CST Construction Suite from a 
Flutter-based mobile application to a high-performance, responsive React Web Application built 
entirely in **JavaScript (ES6+ / JSX)** backed by **Node.js (JavaScript / Express)** and Firebase Services.

The web platform will serve as the primary operational command center for Organizations (Enterprise 
Owners, Managing Directors, Finance Heads) and Managers (Project Heads, General Managers, Site 
Engineers), while maintaining full real-time interoperability with field mobile clients (Supervisors, 
Contractors, Drivers).

Core Principles:
1. Complete Parity: Every existing business rule, approval threshold, financial calculation, and 
   state machine transition must be preserved exactly as currently executed in the mobile app.
2. Responsive Desktop/Tablet Ergonomics: Replace mobile scroll views with rich desktop data grids, 
   multi-column financial comparison matrices, split-pane approval inspectors, and quick-filter toolbars.
3. Multi-Tenant Data Isolation: Strict logical and cryptographic data partitioning across organization 
   tenants (`orgId`).
4. Instantaneous Synchronization: Bidirectional reactive state syncing via Firestore WebSocket listeners 
   and real-time notifications for cross-role collaboration.
5. Pure JavaScript Implementation: Modern, clean JavaScript with ES Modules, PropTypes for runtime 
   validation, and standardized async/await architecture.

2. COMPLETE ORGANIZATION MODULE WORKFLOWS & FUNCTIONAL SPECIFICATION
====================================================================================================

2.1 Organization Landing, Authentication & Subscription Lifecycle
----------------------------------------------------------------------------------------------------
- User Entry: Dedicated corporate login page with email/password and multi-factor capabilities.
- Registration & Org Provisioning:
  * Capture Organization Legal Name, Registration Number, Admin Name, Email, Phone, Office Address, 
    GSTIN, and Corporate Currency.
  * Generates a unique, immutable `orgId`.
- Subscription & PayU Payment Gateway Integration:
  * Plans: Base, Professional, Enterprise (configured by active sites, active managers, storage quota).
  * PayU Checkout Screen with hash verification, payment verification webhook, and automated invoice 
    generation.
  * Enforces subscription limits across Site creation, Manager provisioning, and Document uploads via 
    `subscriptionLimitService.js`.
- Password Reset & Security Center: Secure token-based password reset and active session governance.

2.2 Organization Dashboard & High-Level KPI Matrix
----------------------------------------------------------------------------------------------------
The Organization Dashboard represents the high-level executive control tower.
- Header Metric Banner:
  * Total Active Projects & Active Sites count.
  * Aggregate Material Value in stock across all sites.
  * Active Workforce Count (Daily On-site Workers + Sub-contractor headcount).
  * Cumulative Petty Cash Balance (Total Dispatched vs Total Spent vs Available Balance).
  * Pending Multi-tier Approvals Badge (combining Payments, Materials, Tools, and Workforce).
- Interactive Financial KPI Cards:
  * Total Project Budget vs Cumulative Site Expenses vs Invoiced Value.
  * Burn Rate Analysis (Weekly & Monthly Expense Velocity).
  * Over-budget & Critical Stage Warning Indicators.
- Navigation Quick Hub:
  * Direct jump cards to Projects, Sites, Managers, Workforce, Materials, Tools, Finance, and Reports.

2.3 Project & Site Management
----------------------------------------------------------------------------------------------------
- Project Lifecycle:
  * Create/Edit Project: Project Name, Client Name, Project Code, Budget, Planned Start/End Dates, 
    Project Category (Commercial, Residential, Industrial, Infrastructure).
  * Project Stages: Foundation, Structure, Masonry, MEP, Finishing, Handover (Customizable stage names 
    and estimated percentage weights).
- Site Lifecycle & Spatial Allocation:
  * Add Site under Project: Site Name, Site Code, Address, Geolocation Coordinates, Geofence Radius, 
    Site Budget, Estimated Completion Date.
  * Site Manager Allocation: Map one or more verified Managers to the site.
  * Site Supervisor Allocation: Assign active supervisors to designated site sections or stages.
  * Site Financial Overview: Site-level expenditure breakdown (Materials, Labour, Machinery, Petty Cash, 
    Contractors, Overheads).
  * Layout & Blueprint Drawings Viewer: Support for multi-sheet CAD/PDF/Image blueprint viewing with 
    versioning.

2.4 Manager & Supervisor Administration & Role Mapping
----------------------------------------------------------------------------------------------------
- Manager Provisioning:
  * Create Manager Profile: Full Name, Official Email, Phone, Assigned Department, Employee ID, 
    Account Credentials.
  * Site Mapping: Multi-select sites assigned to the Manager.
  * Permissions & Limits: Custom approval limits for site payments, material requisitions, and cash top-ups.
- Supervisor Roster:
  * View active supervisors across all sites.
  * Re-assign supervisors between sites or revoke active credentials.
  * Track supervisor daily check-ins and GPS clock-in logs.

2.5 Material & Inventory Master Management
----------------------------------------------------------------------------------------------------
- Material Master Catalogue:
  * Hierarchical categorization: Category (e.g., Cement, Steel, Aggregates, Electrical, Plumbing) -> 
    Sub-Category -> Material Item -> Standard Unit of Measurement (Bags, Metric Tonnes, CFT, Meters, Nos).
  * Minimum Threshold Alerts: Configurable low-stock triggers per site.
- Multi-Site Inventory Monitoring:
  * Live cross-site stock matrix: Real-time quantities available at each site warehouse.
  * Inward Delivery Audits: Verification of Goods Received Notes (GRN), delivery challans, supplier invoices, 
    and quality check reports.
  * Inter-Site Material Transfer Approvals: Review transfer requests between site inventories with driver 
    and vehicle dispatch validation.

2.6 Tools & Equipment Central Tracking
----------------------------------------------------------------------------------------------------
- Machinery & Tools Asset Register:
  * Categorization: Heavy Machinery (Excavators, Cranes, Batching Plants), Power Tools (Drills, Cutters, 
    Generators), Hand Tools, Safety Gear.
  * Tracking Fields: Asset Tag / Barcode, Make/Model, Purchase Date, Purchase Price, Maintenance Schedule, 
    Ownership (Owned vs Leased/Rented).
- Movement & Transfer Governance:
  * Review tool dispatch and receipt acknowledgments across sites.
  * Track maintenance downtime, breakdown tickets, and rental billing cycles.

2.7 Petty Cash Corporate Governance
----------------------------------------------------------------------------------------------------
- Cash Account Top-up & Dispatch:
  * Corporate approval for Site Manager & Supervisor Petty Cash Top-up Requests.
  * Fund Dispatch Recording: Transaction Mode (Bank NEFT/RTGS, UPI, Cash), Reference Number, Cheque Number, 
    Payment Date, Transfer Receipt Attachment.
- Central Petty Cash Ledger:
  * Real-time ledger of all vouchers submitted by Supervisors and approved by Managers.
  * Categorized breakdown: Local Site Purchases, Emergency Travel, Daily Food/Tea, Loading/Unloading, 
    Minor Repair.
  * Settlement and balance reconciliation auditing.

2.8 Site Payment Approvals Workflow (3-Tier Approval Pipeline)
----------------------------------------------------------------------------------------------------
The application utilizes an enterprise 3-tier approval lifecycle for all vendor, contractor, and milestone 
payments:
  * Tier 1 (Manager Review): Manager validates site progress, measurement sheet, invoice authenticity, 
    and attaches verification notes.
  * Tier 2 (Organization Approval): Executive/Finance team reviews budget allocation, approves/rejects/holds 
    the payment amount, and selects funding source.
  * Tier 3 (Manager Clearance): Manager issues payment release note, verifies banking transaction reference, 
    and attaches final payment voucher.
- Organization Review Actions:
  * Interactive batch approval / rejection with mandatory reason recording.
  * Dynamic filtering: Pending Org Approval, Approved, Rejected, Cleared.
  * Verification of attached contractor bills, measurement sheets, and supervisor sign-offs.

2.9 Organization Expenses & Financial Accounting
----------------------------------------------------------------------------------------------------
- Expense Ledger:
  * Central ledger tracking all site-level and headquarters overhead expenses.
  * Categories: Site Operational, Contractor Advances, Material Vendor Payments, Equipment Rentals, 
    Staff Payroll, Licensing & Compliance, Utility & Fuel.
- Budget Variance & Cash Flow Analysis:
  * Visual comparison: Planned Budget vs Actual Expense per Project Stage.
  * Cost-to-Complete projections and historical expense burn analytics.

2.10 Corporate Notifications, Real-time Tray Alerts & Routing
----------------------------------------------------------------------------------------------------
- Multi-channel notification dispatch: FCM Web Push, Desktop In-App Banner, and Notification Center Tray.
- Filter Categories: All, Unread, Payments, Materials, Tools, Workforce, Sites, Scheduled.
- Dynamic Action Routing: Clicking any notification immediately deep-links to the corresponding 
  approval screen or record inspector.

2.11 Analytics, Insights & PDF/Excel Reporting Engine
----------------------------------------------------------------------------------------------------
- Comprehensive Report Generation:
  * Daily Site Progress Report (DSR).
  * Comprehensive Financial Status & Stage-wise Expense Variance Report.
  * Material Stock & Inward/Outward Consumption Report.
  * Labour Attendance, Daily Wage & Contractor Incentive Calculation Sheet.
  * Petty Cash Statement & Voucher Reconciliation Sheet.
  * Vehicle Fleet Fuel & Mileage Utilization Report.
- Export Formats: High-resolution PDF with corporate branding/letterhead, and Excel (XLSX/CSV) data sheets.

3. COMPLETE MANAGER MODULE WORKFLOWS & FUNCTIONAL SPECIFICATION
====================================================================================================

3.1 Manager Dashboard & Quick Operation Hub
----------------------------------------------------------------------------------------------------
The Manager Dashboard is the operational workspace for day-to-day site administration.
- Dashboard Highlights:
  * Assigned Sites Overview & Status (Active, On-Hold, Completed).
  * Real-time Daily Attendance summary across assigned sites.
  * Pending Action Counters (Material Requests, Tool Requests, Payment Reviews, Cash Requests).
  * Today's Planned vs Actual Stage Progress.
- Quick Actions Toolbar:
  * Create New Site / Setup Wizard.
  * Dispatch Material / Initiate Transfer.
  * Create Labour Daily Entry / Contractor Measurement.
  * Submit Manager Expense / Cash Advance.
  * Initiate Petty Cash Request.

3.2 Project Configuration & Multi-Step Site Setup Wizard
----------------------------------------------------------------------------------------------------
- Interactive Project & Site Setup Wizard:
  * Step 1: Basic Site Info (Name, Client, Location, Budget, Duration).
  * Step 2: Stage & Sub-Stage Milestones Setup (Weightage %, Deadlines).
  * Step 3: Material Requirement Estimation (BOM - Bill of Materials).
  * Step 4: Supervisor & Sub-Contractor Site Mapping.
  * Step 5: Initial Petty Cash & Tool Allocation.
- Drawing & Document Management:
  * Upload architectural drawings, structural layouts, MEP diagrams, and soil reports.
  * Revision tagging (Rev 1, Rev 2, As-Built) with supervisor access control.

3.3 Daily Site Operations & Supervisor Coordination
----------------------------------------------------------------------------------------------------
- Real-time Supervisor Feed:
  * Monitor supervisor morning clock-ins and evening site progress entries.
  * Live weather, work delays, and hindrance logging (e.g., rain, power outage, material shortage).
  * Photo gallery: Before/after stage execution photos with GPS and timestamp watermarks.

3.4 Workforce Planning, Contractor Entries & Daily Wage Logs
----------------------------------------------------------------------------------------------------
- Direct Workforce Management:
  * Labour Roster: Skill categorization (Mason, Carpenter, Bar Bender, Electrician, Plumber, Helper).
  * Daily Attendance & Wage Recording: Regular Hours, Overtime (OT) Hours, Shift Wage calculation.
- Sub-Contractor Management:
  * Contractor Profiles & Work Orders (Quantity-based vs Rate-based contracts).
  * Daily Contractor Entry: Work measurement (e.g., Sq.ft plastering, Metric Ton steel tying), 
    headcount verification, and daily progress sign-off.
  * Contractor Incentive & Deductions Calculation Engine.

3.5 Material Management (Stock Requisitions, Inward Deliveries, Inter-Site Transfers)
----------------------------------------------------------------------------------------------------
- Site Material Requisitions:
  * Raise material purchase requests to Organization / Central Procurement.
  * Specify item, quantity, urgency (Low, Medium, Critical), and required delivery date.
- Goods Received Note (GRN) Inward Processing:
  * Inspect delivered goods against Purchase Orders.
  * Record delivered quantity, damaged quantity, invoice/challan number, vehicle number, and vendor slip.
  * Instant stock balance auto-increment upon GRN submission.
- Inter-Site Material Transfer:
  * Dispatch stock from Site A to Site B.
  * Assign Driver and Vehicle.
  * Supervisor at receiving Site B performs inward verification before stock leaves in-transit state.

3.6 Tools Movement, Tracking & Site Allocations
----------------------------------------------------------------------------------------------------
- Tool Requisitions: Request tools from central store or adjacent sites.
- Tool Inward / Outward Movement:
  * Issue tools to specific supervisors or sub-contractors with signature / digital acknowledgment.
  * Record tool condition (Good, Minor Wear, Needs Repair, Broken).
  * Schedule routine maintenance and safety certification checks.

3.7 Daily Site Progress Logs & Stage Milestones
----------------------------------------------------------------------------------------------------
- Daily Progress Logging:
  * Percentage completion updates per stage.
  * Concrete pouring logs (Cube test IDs, batching time, slump test results).
  * Milestone verification and sign-off for client billing.

3.8 Site Expenses & Manager Cash Advances
----------------------------------------------------------------------------------------------------
- Expense Incurrence & Logging:
  * Record site operating expenses (local equipment hire, municipal fees, site security, water tankers).
  * Attach GST tax invoices, payment mode, and payee details.
- Manager Cash Advance Account:
  * Track advance funds received from Organization.
  * Balance ledger reconciling total advances against submitted expense bills.

3.9 Petty Cash Operations (Site Requests, Vouchers, Settlements)
----------------------------------------------------------------------------------------------------
- Supervisor Petty Cash Supervision:
  * Review and approve/reject voucher submissions raised by Site Supervisors.
  * View itemized expense receipts and photos.
- Top-Up Requests to Organization:
  * Request petty cash fund replenishment when site balance falls below buffer threshold.
  * Provide justification and audit statement of previous disbursement.

3.10 Site Payment Approval Execution (Stage 1 Review & Stage 3 Clearance)
----------------------------------------------------------------------------------------------------
- Tier 1 Manager Review:
  * Review pending contractor payment claims.
  * Verify physical progress against bill quantities.
  * Approve claim and forward to Organization with technical remarks.
- Tier 3 Manager Clearance:
  * Following Organization approval, Manager verifies actual fund disbursement from corporate account.
  * Enter bank transaction UTR / Reference, date of payment, and issue payment clearance voucher.

3.11 Vehicle & Driver Fleet Management
----------------------------------------------------------------------------------------------------
- Fleet Registry:
  * Track trucks, tippers, tractors, and utility vehicles.
  * Registration Number, Vehicle Type, Capacity, Insurance Expiry, Fitness Certificate (FC) Expiry, 
    Pollution Certificate (PUC).
- Driver Allocation & Trip Logs:
  * Assign verified drivers to specific vehicles.
  * Record trip logs: Origin Site, Destination Site, Material Loaded, Odometer Start/End, Fuel Incurred.

3.12 Manager Notification Feed & Dynamic Deep-Linking Routing
----------------------------------------------------------------------------------------------------
- Centralized Manager Notification Feed:
  * Filter categories: All, Unread, Materials, Tools, Payments, Workforce, Sites.
  * Search by site name, supervisor name, request ID, or keywords.
  * Real-time read/unread sync and "Mark All Read" capability.
- Back Button & Navigation Rule:
  * Exiting the notification center always returns directly to the Manager Dashboard without looping 
    through intermediate screens.
  * Tapping any notification card dynamically deep-links directly into the respective module 
    (Sites, Petty Cash, Materials, Tools Movement, Workforce, Expenses, Site Payments).

3.13 Manager Reports, PDF Exports & Financial Status
----------------------------------------------------------------------------------------------------
- Generate localized Site Reports: Daily Progress, Material Consumption, Tool Inventory, Labour Sheets.
- Instant PDF preview and high-resolution printing.

// Node.js Cloud Function / Express Handler to set Custom Claims

4.5 Firebase Cloud Functions & Background Workers (JavaScript)
----------------------------------------------------------------------------------------------------
```javascript
// Example: onNotificationCreated Cloud Function in JavaScript
const functions = require('firebase-functions');
const admin = require('firebase-admin');

exports.onNotificationCreated = functions.firestore
  .document('organizations/{orgId}/notifications/{notificationId}')
  .onCreate(async (snap, context) => {
    const data = snap.data();
    const { orgId } = context.params;
    const sanitizedOrgId = orgId.replace(/\W/g, '_');
    
    const targetRole = data.targetRole || 'all';
    const topic = targetRole === 'all' 
      ? `org_${sanitizedOrgId}` 
      : `org_${sanitizedOrgId}_${targetRole}`;

    const payload = {
      notification: {
        title: data.title || 'New Notification',
        body: data.body || '',
      },
      data: {
        notificationId: snap.id,
        orgId: orgId,
        requestType: data.requestType || 'general',
        requestId: data.requestId || '',
        siteId: data.siteId || '',
      },
      topic: topic,
    };

    try {
      await admin.messaging().send(payload);
      console.log(`Successfully dispatched FCM message to topic: ${topic}`);
    } catch (error) {
      console.error('Error sending FCM push:', error);
    }
  });
```

4.9 Security Rules (Firestore & Storage)
----------------------------------------------------------------------------------------------------
Firestore Rules enforce strict organization isolation:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    function isAuthenticated() {
      return request.auth != null;
    }
    
    function getUserOrgId() {
      return request.auth.token.orgId;
    }
    
    function getUserRole() {
      return request.auth.token.role;
    }
    
    function isOrgAdmin() {
      return isAuthenticated() && (getUserRole() == 'organisation' || getUserRole() == 'config');
    }
    
    function isManager() {
      return isAuthenticated() && (getUserRole() == 'manager' || isOrgAdmin());
    }

    match /organizations/{orgId}/{document=**} {
      allow read, write: if isAuthenticated() && getUserOrgId() == orgId;
    }
    
    match /organizations/{orgId}/site_payments/{paymentId} {
      allow read: if isAuthenticated() && getUserOrgId() == orgId;
      allow create: if isManager();
      allow update: if isAuthenticated() && getUserOrgId() == orgId;
    }
  }
}
```
