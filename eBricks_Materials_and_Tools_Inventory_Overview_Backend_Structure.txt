1. EXECUTIVE OVERVIEW & PAGE ARCHITECTURE
--------------------------------------------------------------------------------
The Inventory & Assets Overview Page (/organization/inventory) serves as the 
executive control center for all materials, equipment, tools, and site allocations 
across the enterprise. It consolidates real-time stock levels, asset statuses, 
low-stock warnings, pending transfer requisitions, and overall stock valuations into 
a unified, high-performance web dashboard.

Key Design Principles:
  1. Multi-Tenant Organization Isolation:
     All queries strictly execute under `/organisation/{orgId}/data/{collectionName}`.

  2. Unified Inventory & Assets Portal:
     Combines Consumable Materials tracking and Non-Consumable Tools/Machinery tracking 
     into a single navigation entity (`Inventory & Assets`).

  3. Single-Source Hierarchy Integration:
     Organization HQ Central Warehouse ➔ Construction Sites (`siteId`) ➔ Project Stages (`projectId`).

  4. Real-Time Aggregation & Alerts:
     Leverages Firestore reactive subscriptions to immediately reflect inventory 
     movements, low stock warnings, and transit statuses.

2. OVERVIEW PAGE KPI CARDS & DATA METRICS
--------------------------------------------------------------------------------

The top section of the Overview Page renders 8 high-level Executive Summary Cards:

  +--------------------------------------------------------------------------+
  | CARD 1: Total Inventory Stock Value (₹)                                 |
  | Formula: Sum(HQ Material Value) + Sum(All Sites Material Value)          |
  | Query  : /organisation/{orgId}/data/materialsAvailability               |
  | Logic  : Sum(availableQuantity * unitPrice) across all location records  |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 2: Total HQ Central Warehouse Stock Value (₹)                      |
  | Query  : /organisation/{orgId}/data/materialsAvailability               |
  | Filter : siteId == "HQ" || isCompanyWarehouse == true                   |
  | Logic  : Sum(availableQuantity * unitPrice)                              |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 3: Low Stock Alert Items Count                                     |
  | Query  : /organisation/{orgId}/data/materialsAvailability               |
  | Filter : availableQuantity <= minReorderLevel                           |
  | Badge  : Red Warning Badge highlighting urgent reorder items             |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 4: Total Owned Equipment & Machinery Assets Count                  |
  | Query  : /organisation/{orgId}/data/tools                               |
  | Filter : isSerialized == true || ownershipType == "OWNED"               |
  | Logic  : Count of active equipment registry documents                    |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 5: Active Equipment Currently Deployed on Sites                    |
  | Query  : /organisation/{orgId}/data/tools                               |
  | Filter : status == "active_on_site" && currentLocationType == "SITE"    |
  | Logic  : Count of machines currently operating across active sites       |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 6: Equipment Available at HQ Central Warehouse                      |
  | Query  : /organisation/{orgId}/data/tools                               |
  | Filter : status == "at_company_warehouse"                               |
  | Logic  : Count of ready-to-allocate machines stored at HQ                |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 7: Tools & Equipment Under Maintenance / Repair                    |
  | Query  : /organisation/{orgId}/data/tools                               |
  | Filter : status == "under_maintenance" || condition == "DAMAGED"        |
  | Badge  : Amber / Red Alert Badge for broken/servicing equipment          |
  +--------------------------------------------------------------------------+

  +--------------------------------------------------------------------------+
  | CARD 8: Pending Requisitions & Transfers Awaiting Approval              |
  | Query 1: /organisation/{orgId}/data/siteMaterialsRequest (status == "pending_org_approval")
  | Query 2: /organisation/{orgId}/data/siteToolsRequest (status == "pending_org_approval")
  | Logic  : Sum of pending requests requiring Organization HQ action        |
  +--------------------------------------------------------------------------+

4. OVERVIEW PAGE TAB SECTIONS & BACKEND QUERY MAPPING
--------------------------------------------------------------------------------

The Overview Page UI is structured into 4 Primary View Tabs:

[TAB 1: MATERIALS STOCK OVERVIEW & WAREHOUSE MATRIX]
  - Displays: Material Catalog Table, Company Warehouse Balance, Site Stock Balances, Low Stock Warning Badges.
  - Queries:
      a) Fetch All Materials Master Catalog:
         Collection: `/organisation/{orgId}/data/materials`
         Filter    : `where('isActive', '==', true)`
      b) Fetch All Material Stock Ledger Entries:
         Collection: `/organisation/{orgId}/data/materialsAvailability`
         Filter    : Selected Site Filter (e.g. `siteId == selectedSiteId` or "All")

[TAB 2: TOOLS & MACHINERY ASSET REGISTRY]
  - Displays: Serialized Machinery Status Grid, Asset Tags, Current Site Location, Maintenance Due Dates, Rental vs Owned Breakdown.
  - Queries:
      a) Fetch All Equipment Master Records:
         Collection: `/organisation/{orgId}/data/tools`
         Filter    : Optional category / site / status filter
      b) Fetch Bulk Tool Quantities:
         Collection: `/organisation/{orgId}/data/toolsInventory`

[TAB 3: REQUISITIONS & TRANSFER ALLOCATION HUB]
  - Displays: Pending Supervisor Requests, Manager Clearance Queue, Active In-Transit Vehicles, Completed Transfer Manifests.
  - Queries:
      a) Material Requests:
         Collection: `/organisation/{orgId}/data/siteMaterialsRequest`
         Filter    : `orderBy('createdAt', 'desc')`
      b) Tool Requests:
         Collection: `/organisation/{orgId}/data/siteToolsRequest`
         Filter    : `orderBy('createdAt', 'desc')`
      c) Active In-Transit Movements:
         Collection: `/organisation/{orgId}/data/materialTransfer`
         Filter    : `where('status', '==', 'IN_TRANSIT')`

[TAB 4: INVENTORY MOVEMENT AUDIT & HISTORY LEDGER]
  - Displays: Real-time chronological transaction stream (Purchases, Dispatches, Receipts, Usage Logs).
  - Query:
      Collection: `/organisation/{orgId}/data/materialmovementhistory`
      Filter    : `orderBy('timestamp', 'desc')`, `limit(50)`

5. FRONTEND STATE MANAGEMENT & SERVICE CONTROLLER BLUEPRINT
--------------------------------------------------------------------------------

The Web Application service layer (`services/inventoryService.js`) implements the 
following backend interface methods:

```javascript
// 1. Fetch Real-time Executive Overview KPIs
export const subscribeInventoryOverviewKPIs = (orgId, onUpdate) => {
  const materialsRef = collection(db, 'organisation', orgId, 'data', 'materialsAvailability');
  const toolsRef = collection(db, 'organisation', orgId, 'data', 'tools');
  const matReqRef = collection(db, 'organisation', orgId, 'data', 'siteMaterialsRequest');

  // Reactively list stock & aggregate totals client-side for zero latency
  return onSnapshot(materialsRef, (snapshot) => {
    let totalStockValue = 0;
    let hqStockValue = 0;
    let lowStockCount = 0;

    snapshot.docs.forEach((doc) => {
      const data = doc.data();
      const available = data.availableQuantity || 0;
      const price = data.unitPrice || 0;
      const minLevel = data.minReorderLevel || 0;

      const itemVal = available * price;
      totalStockValue += itemVal;

      if (data.siteId === 'HQ' || data.isCompanyWarehouse) {
        hqStockValue += itemVal;
      }

      if (available <= minLevel && minLevel > 0) {
        lowStockCount++;
      }
    });

    onUpdate({
      totalStockValue,
      hqStockValue,
      lowStockCount
    });
  });
};

// 2. Fetch Low Stock Warning List
export const fetchLowStockAlerts = async (orgId) => {
  const ref = collection(db, 'organisation', orgId, 'data', 'materialsAvailability');
  const snapshot = await getDocs(ref);
  const alerts = [];
  snapshot.forEach(doc => {
    const data = doc.data();
    if ((data.availableQuantity || 0) <= (data.minReorderLevel || 0)) {
      alerts.push(data);
    }
  });
  return alerts;
};

// 3. Fetch Equipment Status Distribution
export const fetchEquipmentStatusSummary = async (orgId) => {
  const ref = collection(db, 'organisation', orgId, 'data', 'tools');
  const snapshot = await getDocs(ref);
  const summary = {
    totalCount: 0,
    atWarehouse: 0,
    activeOnSite: 0,
    underMaintenance: 0
  };

  snapshot.forEach(doc => {
    const data = doc.data();
    summary.totalCount++;
    if (data.status === 'at_company_warehouse') summary.atWarehouse++;
    if (data.status === 'active_on_site') summary.activeOnSite++;
    if (data.status === 'under_maintenance' || data.condition === 'DAMAGED') summary.underMaintenance++;
  });

  return summary;
};
```
