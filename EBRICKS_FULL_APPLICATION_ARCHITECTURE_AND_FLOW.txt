1. SYSTEM ARCHITECTURE & MULTI-TENANCY MODEL
====================================================================================================

1.1. Organization Namespacing (Multi-Tenancy)
The entire eBricks data layer is strictly multi-tenant, partitioned by Organization ID (`orgId` / `organizationId`).
All Firestore access flows through centralized services (`FirestoreService`, `PettyCashService`, `MaterialInventoryService`, etc.) ensuring zero cross-tenant data leaks.

Path Resolution Pattern:
  - Standard Org Collection: `/organisation/{orgId}/{collectionName}`
  - Example: `/organisation/cst_org_123/projects`
  - Example: `/organisation/cst_org_123/materials`
  - Global Root Collections (Shared/System-Level):
      * `/users/{uid}` (Global User Profiles & Org Pointers)
      * `/organisations/{orgId}` (Organization Root Metadata & Settings)
      * `/invitations/{inviteId}` (Referral / Onboarding Codes)
      * `/system_config` (Feature Flags & App Configuration)
      * `/subscription_plans` (Plan Tier Definitions)

1.2. Legacy Path Backward-Compatibility Engine:
In `FirestoreService.dart`, legacy table names are dynamically aliased:
  - 'Site' / 'sites'        ==> redirected to 'projects'
  - 'Material'              ==> redirected to 'materials'
  - 'Contractor'            ==> redirected to 'contractors'
  - 'Worker' / 'Labour'     ==> redirected to 'workers'
  - 'Vehicle'               ==> redirected to 'vehicles'
  - 'Tool' / 'Machinery'    ==> redirected to 'tools'

2. ROLE-BASED ACCESS CONTROL (RBAC) & PERMISSION MATRIX
====================================================================================================

| Role          | Platform Support       | Primary Scope & Permissions                                                                                   |
|---------------|------------------------|---------------------------------------------------------------------------------------------------------------|
| Organization  | Web Portal & Mobile    | Full tenant ownership. Multi-project financial oversight, subscription billing (PayU), user & role governance, master catalog management, system configurations, high-value approvals. |

3. BACKEND FIRESTORE DATA DICTIONARY & SCHEMA SPECIFICATION
====================================================================================================

3.1. Collection: `/users` (Root)
----------------------------------------------------------------------------------------------------
* Purpose: User identity, system-wide role mapping, profile credentials, FCM tokens.
* Document ID: `{uid}` (Firebase Auth UID)
* Fields:
  - `uid` (String): Unique Auth UID
  - `email` (String): User email address
  - `phoneNumber` (String): Mobile contact
  - `displayName` (String): Full name of the user
  - `role` (String): 'organization' | 'manager' | 'supervisor' | 'customer' | 'contractor'
  - `organizationId` (String): Linked Organization ID (`cst_...`)
  - `assignedProjects` (List<String>): List of Project IDs the user is assigned to
  - `fcmTokens` (List<String>): Device Push Notification Tokens
  - `status` (String): 'active' | 'suspended' | 'invited'
  - `profileImageUrl` (String): Cloud Storage URL
  - `createdAt` (Timestamp): Registration date
  - `updatedAt` (Timestamp): Last update timestamp

3.2. Collection: `/organisations` (Root) & `/organisation/{orgId}`
----------------------------------------------------------------------------------------------------
* Purpose: Organization settings, legal credentials, branding, plan subscriptions, fiscal settings.
* Document ID: `{orgId}`
* Fields:
  - `orgId` (String): Organization Identifier
  - `companyName` (String): Registered Company / Firm Name
  - `logoUrl` (String): Branding Logo
  - `gstNumber` (String): GSTIN / Tax ID
  - `panNumber` (String): Legal PAN
  - `address` (Map): `{ street, city, state, postalCode, country }`
  - `contactPerson` (Map): `{ name, email, phone }`
  - `subscription` (Map): `{ planId, planName, status: 'active'|'trial'|'expired', startDate, endDate, maxProjects, maxUsers, maxStorageGb, transactionId }`
  - `branding` (Map): `{ primaryColor, secondaryColor, appTitle, customDomain }`
  - `currency` (String): 'INR' | 'USD' | 'AED' (Default: 'INR')
  - `fiscalYearStart` (String): '04-01'
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.3. Collection: `/organisation/{orgId}/projects` (Sites / Projects)
----------------------------------------------------------------------------------------------------
* Purpose: Core project master data, stages, budget, site geofencing, assignments, milestones.
* Document ID: `{projectId}`
* Fields:
  - `projectId` (String): Unique Project ID
  - `name` (String): Site Name (e.g., "Skyline Heights - Phase 1")
  - `code` (String): Project Code (e.g., "PRJ-2026-001")
  - `clientName` (String): Customer / Client Name
  - `clientPhone` (String): Customer Contact
  - `clientEmail` (String): Customer Email
  - `customerId` (String): Linked User UID (Customer role)
  - `managerId` (String): Assigned Manager UID
  - `managerName` (String): Assigned Manager Name
  - `supervisorIds` (List<String>): Assigned Supervisor UIDs
  - `location` (Map): `{ address, city, state, pinCode, geoPoint: GeoPoint(lat, lng), radiusMeters: 500 }`
  - `startDate` (Timestamp): Expected start
  - `estimatedEndDate` (Timestamp): Expected finish
  - `actualEndDate` (Timestamp): Actual completion date
  - `totalBudget` (Double): Total estimated cost
  - `spentAmount` (Double): Real-time calculated expenditure
  - `receivedAmount` (Double): Inflow from customer/client
  - `status` (String): 'planned' | 'in_progress' | 'on_hold' | 'completed' | 'archived'
  - `currentStage` (String): Current active construction milestone
  - `stages` (List<Map>): `[{ stageId, name, order, status: 'pending'|'in_progress'|'completed', completionPercentage, startDate, endDate }]`
  - `drawings` (List<Map>): `[{ id, title, category: 'architectural'|'structural'|'mep', fileUrl, uploadedAt, version }]`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.4. Collection: `/organisation/{orgId}/materials` & `/organisation/{orgId}/material_inventory`
----------------------------------------------------------------------------------------------------
* Purpose: Material catalog, inventory stock levels, warehouse / site allocations.
* Document ID: `{materialId}`
* Fields:
  - `materialId` (String): Unique Material ID
  - `name` (String): Material Name (e.g., "TMT Steel 12mm", "OPC 53 Cement")
  - `category` (String): 'Cement' | 'Steel' | 'Aggregates' | 'Bricks' | 'Electrical' | 'Plumbing' | 'Paints' | 'Hardware'
  - `unit` (String): 'Bags' | 'Tons' | 'Kg' | 'Sq.Ft' | 'Cu.M' | 'Litres' | 'Pieces'
  - `standardRate` (Double): Unit procurement price
  - `hsnCode` (String): Tax HSN Code
  - `minReorderLevel` (Double): Safety threshold quantity
  - `currentTotalStock` (Double): Global organization stock
  - `siteStock` (Map<String, Double>): Map of `{ projectId: quantity }`
  - `isApproved` (Boolean): Master catalog approval
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.5. Collection: `/organisation/{orgId}/material_requests` (Indents / Transfers / GRN)
----------------------------------------------------------------------------------------------------
* Purpose: Material Indents requested by supervisors, manager approvals, Goods Received Notes (GRN).
* Document ID: `{requestId}`
* Fields:
  - `requestId` (String): Unique Indent ID
  - `projectId` (String): Target Site ID
  - `projectName` (String): Site Name
  - `requestedByUid` (String): Supervisor UID
  - `requestedByName` (String): Supervisor Name
  - `items` (List<Map>): `[{ materialId, materialName, unit, requestedQty, approvedQty, receivedQty, unitRate, totalEstimatedCost }]`
  - `status` (String): 'pending_manager' | 'approved' | 'rejected' | 'ordered' | 'partially_received' | 'received'
  - `urgency` (String): 'low' | 'medium' | 'high' | 'critical'
  - `deliveryExpectedDate` (Timestamp)
  - `supplierId` (String): Selected Vendor/Supplier ID
  - `supplierName` (String): Selected Vendor Name
  - `poNumber` (String): Purchase Order Reference
  - `grnReceipts` (List<Map>): `[{ grnId, receivedDate, receivedBy, billUrl, invoiceNumber, receivedItems: [...] }]`
  - `managerApproval` (Map): `{ approvedBy, approvedAt, remarks }`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.6. Collection: `/organisation/{orgId}/petty_cash_accounts`
----------------------------------------------------------------------------------------------------
* Purpose: Supervisor spendable float balances, allocated funds, spent tracking.
* Document ID: `{supervisorUid}` or `{supervisorUid}_{projectId}`
* Fields:
  - `accountId` (String): Unique Account ID
  - `supervisorUid` (String): Supervisor User UID
  - `supervisorName` (String): Full Name
  - `organizationId` (String): Org ID
  - `projectId` (String, Optional): Specific project link (if site-tied float)
  - `currentBalance` (Double): Net Spendable Balance (Total Disbursed - Total Spent - Total Returned)
  - `totalAllocated` (Double): Cumulative lifetime approved float
  - `totalSpent` (Double): Cumulative approved site + non-site expenses
  - `totalReturned` (Double): Total cash handed back during reconciliations
  - `lastDisbursementDate` (Timestamp)
  - `lastExpenseDate` (Timestamp)
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.7. Collection: `/organisation/{orgId}/petty_cash_requests`
----------------------------------------------------------------------------------------------------
* Purpose: Float replenishment requests submitted by supervisors to Manager/Organization.
* Document ID: `{requestId}`
* Fields:
  - `requestId` (String): Unique Request ID
  - `supervisorUid` (String): Requesting Supervisor UID
  - `supervisorName` (String): Supervisor Name
  - `amount` (Double): Requested Float Amount
  - `category` (String): 'site_expense' | 'other_operational'
  - `projectId` (String, Optional): Target Site ID (null if other operational)
  - `projectName` (String, Optional): Target Site Name
  - `reason` (String): Purpose of replenishment
  - `status` (String): 'pending_manager' | 'approved' | 'disbursed' | 'rejected'
  - `paymentMode` (String): 'cash' | 'bank_transfer' | 'upi'
  - `disbursedBy` (String): Manager / Org User UID
  - `disbursedAt` (Timestamp)
  - `rejectionReason` (String)
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.8. Collection: `/organisation/{orgId}/petty_cash_expenses`
----------------------------------------------------------------------------------------------------
* Purpose: Actual receipts / bills spent out of petty cash float.
* Document ID: `{expenseId}`
* Fields:
  - `expenseId` (String): Unique Expense ID
  - `supervisorUid` (String): Submitting Supervisor UID
  - `supervisorName` (String): Submitting Supervisor Name
  - `projectId` (String, Optional): Linked Site ID
  - `projectName` (String, Optional): Linked Site Name
  - `expenseType` (String): 'site_expense' | 'other_operational'
  - `category` (String): 'materials_local' | 'labour_daily' | 'equipment_fuel' | 'transport_cartage' | 'refreshments' | 'office_stationery' | 'repairs' | 'miscellaneous'
  - `amount` (Double): Expense Amount
  - `date` (Timestamp): Expense Date
  - `description` (String): Justification / Description
  - `vendorName` (String): Local Vendor / Supplier
  - `billReceiptUrl` (String): Cloud Storage Bill Photo
  - `status` (String): 'submitted' | 'approved' | 'rejected' | 'reconciled'
  - `approvedBy` (String): Reviewing Manager UID
  - `approvedAt` (Timestamp)
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.9. Collection: `/organisation/{orgId}/contractors` & `/organisation/{orgId}/contractor_bills`
----------------------------------------------------------------------------------------------------
* Purpose: Sub-contractor masters, task agreements, stage-wise billing, measurement sheets, payments.
* Fields:
  - `contractorId` (String): Unique Contractor ID
  - `name` (String): Contractor / Firm Name
  - `trade` (String): 'Civil' | 'Electrical' | 'Plumbing' | 'Centering' | 'Painting' | 'Flooring' | 'Fabrication'
  - `phone` (String): Contact Number
  - `panGst` (String): Tax ID
  - `workOrders` (List<Map>): `[{ workOrderId, projectId, workDescription, agreedRate, rateUnit: 'Sq.Ft'|'LumpSum'|'Running.Ft', totalContractValue, advancePaid, balanceDue }]`
  - `bills` (List<Map>): `[{ billId, workOrderId, projectId, billNumber, measurementSheetUrl, measuredQty, rate, grossAmount, tdsDeduction, retentionDeduction, netPayable, status: 'submitted'|'approved'|'paid' }]`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.10. Collection: `/organisation/{orgId}/workers` & `/organisation/{orgId}/worker_attendance`
----------------------------------------------------------------------------------------------------
* Purpose: Daily muster roll, labour rates (Mason, Helper, Carpenter, Barbender), daily attendance logs, wage payouts.
* Fields:
  - `workerId` (String): Worker ID
  - `name` (String): Worker Name
  - `skillType` (String): 'Skilled' (Mason, Plumber) | 'Semi-Skilled' | 'Unskilled' (Male/Female Helper)
  - `dailyWageRate` (Double): Standard Daily Wage
  - `overtimeHourlyRate` (Double): OT Rate
  - `assignedProjectId` (String): Current Site
  - `attendanceRecord`: `{ date: 'YYYY-MM-DD', status: 'present'|'half_day'|'absent'|'overtime_hours', shift: 'morning'|'night', wageCalculated, supervisorRecordedUid }`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.11. Collection: `/organisation/{orgId}/tools` & `/organisation/{orgId}/tool_allocations`
----------------------------------------------------------------------------------------------------
* Purpose: Machinery, heavy equipment, scaffolding, power tools inventory and site transfers.
* Fields:
  - `toolId` (String): Tool/Equipment ID
  - `name` (String): Equipment Name (e.g., "Concrete Mixer 10/7", "Vibrator Needle", "Total Station")
  - `modelSerial` (String): Asset Identification Code
  - `category` (String): 'Heavy Machinery' | 'Power Tools' | 'Safety Equipment' | 'Survey Instruments'
  - `ownershipType` (String): 'owned' | 'rented'
  - `currentStatus` (String): 'in_yard' | 'allocated_to_site' | 'under_maintenance' | 'decommissioned'
  - `currentProjectId` (String, Optional): Current Location
  - `allocationHistory` (List<Map>): `[{ allocationId, fromSiteId, toSiteId, dispatchedBy, receivedBy, dispatchDate, returnDate, conditionOnReturn }]`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.12. Collection: `/organisation/{orgId}/vehicles` & `/organisation/{orgId}/vehicle_logs`
----------------------------------------------------------------------------------------------------
* Purpose: Transport logistics, tippers, tractors, supervisor bikes, fuel logs, driver trips.
* Fields:
  - `vehicleId` (String): Vehicle ID
  - `registrationNumber` (String): e.g., "MH-12-AB-1234"
  - `type` (String): 'Tipper/Dumper' | 'Tractor' | 'Transit Mixer' | 'Pickup Truck' | 'Two-Wheeler'
  - `driverName` (String): Driver In-charge
  - `driverPhone` (String)
  - `currentOdometer` (Double): Current KM reading
  - `fuelLogs` (List<Map>): `[{ date, liters, cost, odometer, fuelBillUrl, filledBy }]`
  - `tripLogs` (List<Map>): `[{ date, fromLocation, toLocation, purpose, materialCarried, kmRun, driverSign }]`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.13. Collection: `/organisation/{orgId}/quality_checklists` & `/organisation/{orgId}/safety_incidents`
----------------------------------------------------------------------------------------------------
* Purpose: QA/QC Inspection checklists, snag lists, site safety compliance, incident reports.
* Fields:
  - `checklistId` (String): Inspection ID
  - `projectId` (String): Site ID
  - `stage` (String): Construction Stage
  - `inspectionType` (String): 'Reinforcement Pre-Pour' | 'Concrete Cube Test' | 'Brickwork Plumb' | 'Waterproofing' | 'Electrical Conduit'
  - `inspectedBy` (String): Inspector/Manager UID
  - `inspectionDate` (Timestamp)
  - `items` (List<Map>): `[{ checkItem, standardValue, observedValue, status: 'pass'|'fail'|'rectification_required', photoUrl, remarks }]`
  - `snagList` (List<Map>): `[{ snagId, description, severity: 'minor'|'major'|'critical', assignedTo, status: 'open'|'resolved', resolvedPhotoUrl }]`
  - `safetyIncidents` (List<Map>): `[{ incidentId, date, description, severity, injuredPerson, actionTaken, reportedBy }]`
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.14. Collection: `/organisation/{orgId}/customer_invoices` & `/organisation/{orgId}/customer_payments`
----------------------------------------------------------------------------------------------------
* Purpose: Stage milestone billing to clients, tax invoices, receipt generation, PayU gateway logs.
* Fields:
  - `invoiceId` (String): Unique Invoice ID
  - `invoiceNumber` (String): Formatted Invoice Number (e.g., "INV/2026/042")
  - `projectId` (String): Linked Site ID
  - `customerId` (String): Customer UID
  - `customerName` (String): Customer Full Name
  - `stageId` (String): Triggered Milestone Stage
  - `baseAmount` (Double): Milestone Value
  - `taxGstAmount` (Double): GST calculated (e.g. 18%)
  - `totalPayable` (Double): Base + Tax
  - `dueDate` (Timestamp)
  - `status` (String): 'draft' | 'issued' | 'partially_paid' | 'paid' | 'overdue'
  - `payments` (List<Map>): `[{ paymentId, date, amount, method: 'PayU'|'NEFT'|'Cheque'|'Cash', transactionRef, receiptUrl, status }]`
  - `pdfUrl` (String): Rendered PDF Invoice stored in Firebase Storage
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

3.15. Collection: `/organisation/{orgId}/daily_site_logs`
----------------------------------------------------------------------------------------------------
* Purpose: End-of-day supervisor progress summaries, weather, workforce count, equipment runtime, hindrances.
* Fields:
  - `logId` (String): Unique Log ID

  - `date` (String): 'YYYY-MM-DD'
  - `supervisorUid` (String): Submitting Supervisor
  - `weather` (String): 'Sunny' | 'Rainy' | 'Cloudy' | 'High Winds'

  - `workforceCount` (Map): `{ masons: 5, helpers: 12, carpenters: 3, electricians: 2, total: 22 }`
  - `equipmentOnSite` (List<String>)
  - `hindrances` (String): Bottlenecks / delays encountered (e.g., cement delay, power cut)
  - `sitePhotos` (List<String>): Geo-tagged and timestamped progress photos
  - `managerReviewed` (Boolean): Manager sign-off status
  - `createdAt` (Timestamp)
  - `updatedAt` (Timestamp)

  - `createdAt` (Timestamp)

     * System validates `/invitations/{code}`.

   - Data Operations:
     * Read: `/invitations/{code}`
     * Write: `/users/{uid}`
     * Update: `/invitations/{code}` (status: 'accepted', usedBy: uid)

     * Read/Update: `/users/{uid}`
     * Upload: Firebase Storage `/avatars/{uid}.jpg`

5. BACKEND APIS, CLOUD FUNCTIONS & THIRD-PARTY INTEGRATIONS
====================================================================================================

5.1. Firebase Cloud Functions (`functions/index.js` & `functions/services/`)
----------------------------------------------------------------------------------------------------
1. `initiatePayuPayment(data, context)`
   - Computes SHA-512 hash signature using PayU Merchant Key & Salt.
   - Prepares transaction record in `/organisation/{orgId}/payu_transactions`.
   - Returns encrypted payload to client for browser/SDK redirection.

2. `verifyPayuPaymentWebhook(req, res)`
   - Server-to-server callback endpoint.
   - Verifies PayU reverse hash signature.
   - Updates target Invoice status (`paid`) or Subscription plan record (`active`).

3. `sendInvoiceEmail(data, context)`
   - Generates PDF invoice using HTML template.
   - Dispatches email with PDF attachment via Nodemailer SMTP to customer/client.

4. `sendPaymentReminderEmail(data, context)`
   - Sends automated milestone payment reminders with direct payment link.

5. `sendPushNotification(data, context)`
   - Dispatches FCM payload to target device tokens based on workflow events:
     * Indent raised -> Notifies Manager.
     * Petty cash allocated -> Notifies Supervisor.
     * Snag logged -> Notifies Sub-contractor/Supervisor.

6. `checkSubscriptionExpiryScheduled(cron: "0 0 * * *")`
   - Daily cron job evaluating active subscriptions.
   - Transitions expired organizations to grace period / read-only mode.

5.2. Firebase Cloud Storage Bucket Hierarchy
----------------------------------------------------------------------------------------------------
- `/organisations/{orgId}/logos/`
- `/projects/{projectId}/drawings/{version}/`
- `/projects/{projectId}/site_photos/{date}/`
- `/petty_cash/{supervisorUid}/bills/{expenseId}.jpg`
- `/materials/{indentId}/grn_bills/`
- `/contractors/{contractorId}/mb_sheets/`
- `/invoices/{invoiceId}.pdf`
