1. EXECUTIVE WORKFORCE ARCHITECTURE & LIFECYCLE DOMAIN
================================================================================

1.1 DOMAIN TAXONOMY: TRADES VS WORKERS VS SITE DEPLOYMENTS VS ATTENDANCE
------------------------------------------------------------------------
In a construction management enterprise, workforce governance is divided into 
four distinctly governed entities:

A. Master Labour Trades (`labours`):
   Standardized construction trades and base daily wage benchmarks (e.g., Mason, 
   Carpenter, Electrician, Plumber, Barbender, Welder, Painter, Helper). These 
   define company-approved job descriptions and benchmark day wages.

B. Registered Worker Master (`workersConfig`):
   The central directory of identified, registered physical workers across all sites. 
   Stores personal metadata (Full Name, 10-digit Phone Number, Residential Address, 
   Assigned Trade/Designation, Base Daily Wage, and Registration Date).

C. Site-Worker Mapping & Deployment (`workerSiteMapping`):
   The active allocation of workers to specific physical construction project sites. 
   Ensures one-to-one availability tracking (a worker cannot be simultaneously 
   deployed to two active sites without an explicit transfer audit).

D. Attendance & Payroll Calculations (`workersAttendance` & `WorkerMonthlyAttendance`):
   Daily on-site muster rolls captured by site supervisors, directly feeding 
   the worker-level monthly wage accumulation engine based on verified present, 
   half-day, and overtime days.

1.2 MULTI-TENANT ORGANIZATION PATH SCOPING
------------------------------------------
Every database query, document mutation, listener, and batch write strictly 
executes inside the organization boundary:
  `/organisation/{orgId}/{collectionName}`

Where:
- `{orgId}`: Active Organization ID derived from auth session context 
  (e.g., `CST_ORG_001`, `ebricks_construction`).
- No workforce profile, requisition, or attendance record is accessible outside 
  its enclosing organization boundary.

1.3 THE 5-PHASE WORKFORCE OPERATIONAL LIFECYCLE
------------------------------------------------
Phase 1: Configuration & Registration
   - Manager / Org Admin creates standard trades and baseline salaries in `labours`.
   - Manager registers individual workforce personnel into `workersConfig`.

Phase 2: Stage Requisition & Indent (Supervisor Initiation)
   - Site Supervisor identifies labour demand for an upcoming project stage (e.g., 
     Roof Slab Casting requires 4 Masons, 6 Helpers for 3 days).
   - Submits workforce requisition to `siteSupervisorProjectStageSchedule`.

Phase 3: Multi-Tier Approval Governance
   - Stage 1: Manager Reviews, adjusts labour quotas, and forwards to Organization.
   - Stage 2: Organization HQ reviews budget & wage ceiling, authorizing the indent.
   - Stage 3: Manager conducts final clearance, schedules dispatch, and notifies site.

Phase 4: Worker-to-Site Mapping & Deployment
   - Manager assigns specific registered workers from `workersConfig` to the 
     project site in `workerSiteMapping`.
   - Automatic cross-site de-allocation handles any worker transferred from another site.

Phase 5: On-Site Attendance, Verification & Wage Accrual
   - Supervisor marks daily attendance on site (`workersAttendance`).
   - System updates `WorkerMonthlyAttendance` atomically with daily wage accruals.

2.3 WORKER SITE MAPPING & DEPLOYMENT ENGINE (`WorkerMappingPage`)
--------------------------------------------------------------------------------
Path: `/manager/workforce/worker-site-mapping`
Purpose: Allocate registered workers to physical construction sites. Track worker 
availability and resolve cross-site scheduling conflicts.

[UI Structure & Workflow]
1. Site & Project Selection Section:
   - Site Dropdown: Populated from `/organisation/{orgId}/projects` (or legacy `Site`).
     Displays: `{siteName} ({siteId})`.
   - Selected Site Context Box:
     * Site ID: Displayed in read-only pill.
     * Project Name: Inherited from project record.
     * Assigned Supervisor: Displayed dynamically (queried from `projects.assignedSupervisor` 
       or `siteSupervisorMap`).
2. Current Site Worker Roster (Real-Time Listener):
   - Streams live document from `/organisation/{orgId}/workerSiteMapping/{siteId}`.
   - Shows all currently deployed workers with: Name, Trade, Daily Salary, Phone, Mapping Date.
3. Worker Selector & Allocation Interface:
   - Worker Dropdown: Lists all registered workers from `workersConfig`.
   - Live Conflict Badge:
     * System checks if the selected worker is already assigned to another site in `workerSiteMapping`.
     * If assigned elsewhere: Displays warning banner: 
       "⚠️ Worker '{workerName}' is currently mapped to Site '{prevSiteName}'. 
        Adding here will transfer them from {prevSiteName}."
   - "Add Worker to Site" Button:
     * Appends worker map to local staging roster list:
       `{ workerId, workerName, workerDesignation, workerSalary, workerPhone, siteId, siteName, assignmentStatus: 'Active', mappingDate: 'dd/MM/yyyy' }`.
     * Prevents duplicate additions to the same site staging list.
4. Staging Roster Table:
   - Lists all workers queued for this site.
   - Allows removing workers (`X` icon) prior to final submission.
5. Save & Dispatch Button:
   - "Confirm & Deploy Workers ({count})"
   - Backend Atomic Execution:
     * Merges update into `workerSiteMapping/{siteId}` and mirror `workerSiteMap/{siteId}`.
     * Cross-Site Transfer Cleanup: Iterates over all other sites in `workerSiteMapping`. 
       If any newly added worker ID exists in another site's `workers` array, removes 
       them from that site atomically.
     * Dispatches notification to site supervisor:
       "Workforce Deployment: {count} workers assigned to {siteName}."

2.6 MONTHLY ATTENDANCE & PAYROLL RECALCULATION
--------------------------------------------------------------------------------
Collection: `WorkerMonthlyAttendance`
Document ID: `{workerId}_{yyyy-MM}` (e.g. `WC001_2026-09`)

Recalculation Formula (Executed in Batch on Every Attendance Submission):
```
totalSalary = 0.0
presentDays = 0

For each day in attendanceData:
   if (status == "present" || status == "overtime"):
       totalSalary += salaryPerDay
       presentDays += 1
   else if (status == "half day"):
       totalSalary += (salaryPerDay / 2.0)
       presentDays += 1
   else: // absent
       // 0 wage added

calculatedSalary = totalSalary
totalPresentDays = presentDays
```

State Representation Constants:
1. `pending_manager_review`:

   - Status Display: "Pending Manager Review"
   - Permitted Roles: Manager can Approve (Forward) or Reject.
2. `pending_org_approval`:
   - Step Number: 2

   - Permitted Roles: Organization Admin can Authorize or Reject.
3. `pending_manager_clearance`:
   - Step Number: 3
   - Status Display: "Pending Manager Clearance"
   - Permitted Roles: Manager can issue Final Clearance & Release.
4. `approved`:
   - Step Number: 4
   - Status Display: "Approved & Released"

5. `rejected_by_manager` / `rejected_by_org`:
   - Step Number: -1
   - Status Display: "Rejected by Manager" / "Rejected by Organization"
   - Stores `rejectionReason`, `rejectedBy`, `rejectedRole`.

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Helper functions
    function isAuthenticated() {
      return request.auth != null;
    }

    function isOrgMember(orgId) {
      return isAuthenticated() && 
        (request.auth.token.orgId == orgId || 
         request.auth.token.role == 'super_admin');
    }

    function isOrgAdmin(orgId) {
      return isOrgMember(orgId) && 
        (request.auth.token.role == 'organization' || 
         request.auth.token.role == 'admin');
    }

    function isManager(orgId) {
      return isOrgMember(orgId) && 
        (request.auth.token.role == 'manager' || 
         isOrgAdmin(orgId));
    }

    function isSupervisor(orgId) {
      return isOrgMember(orgId) && 
        (request.auth.token.role == 'supervisor' || 
         isManager(orgId));
    }

    match /organisation/{orgId} {
      
      // 1. Labour Trade Masters
      match /labours/{labourId} {
        allow read: if isOrgMember(orgId);
        allow create, update: if isManager(orgId);
        allow delete: if isOrgAdmin(orgId);
      }

      // 2. Worker Master Directory
      match /workersConfig/{workerId} {
        allow read: if isOrgMember(orgId);
        allow create, update: if isManager(orgId);
        allow delete: if isOrgAdmin(orgId);
      }

      // 3. Worker Site Mapping
      match /workerSiteMapping/{siteDocId} {
        allow read: if isOrgMember(orgId);
        allow write: if isManager(orgId);
      }
      match /workerSiteMap/{siteDocId} {
        allow read: if isOrgMember(orgId);
        allow write: if isManager(orgId);
      }

      // 4. Workforce Stage Requisitions
      match /siteSupervisorProjectStageSchedule/{scheduleDocId} {
        allow read: if isOrgMember(orgId);
        allow create: if isSupervisor(orgId);
        allow update: if isManager(orgId) || isOrgAdmin(orgId);
        allow delete: if isOrgAdmin(orgId);
      }

      // 5. Daily Attendance
      match /workersAttendance/{attendanceDocId} {
        allow read: if isOrgMember(orgId);
        allow write: if isSupervisor(orgId);
      }

      // 6. Monthly Attendance & Payroll Ledger
      match /WorkerMonthlyAttendance/{workerMonthDocId} {
        allow read: if isManager(orgId);
        allow write: if isSupervisor(orgId) || isManager(orgId);
      }
    }
  }
}
```

6. VALIDATION RULES, ERROR HANDLING & BUSINESS GUARDRAILS
================================================================================

6.1 FRONTEND INPUT VALIDATIONS
------------------------------
1. Worker Registration:
   - Full Name: Minimum 2 characters, alphanumeric with spaces, cannot be blank.
   - Mobile Number: Exactly 10 digits (`^[0-9]{10}$`). Invalid length or non-digits 
     trigger immediate red error state: "Phone number must be exactly 10 digits".
   - Trade / Designation: Must select an active trade from `labours`.
   - Salary: Must be a positive numeric value $> 0$.
   - Joining Date: Valid date format (`yyyy-MM-dd`), cannot be a future date exceeding 30 days.

2. Trade Registration:
   - Designation: Unique within organization (case-insensitive duplicate verification).
   - Daily Salary: Numeric value $> 0$.

3. Worker Site Mapping:
   - Must select an active Site ID.
   - At least 1 worker must be added before submission.
   - Duplicate worker check: Prevent adding the same worker twice to the staging roster.
   - Conflict detection: If worker exists in another site, alert manager of automatic transfer.

4. Daily Attendance:
   - Every mapped worker MUST have an explicit status (`Present`, `Absent`, `Half Day`, `Overtime`).
   - Unmarked workers block submission with warning: 
     "Please mark attendance for all {count} mapped worker(s)".

6.2 CONCURRENCY & BATCH ATOMICITY
---------------------------------
All multi-document operations execute inside Firestore Batched Writes (`writeBatch`):
1. Worker Deployment:
   - Writes to `workerSiteMapping/{siteId}`.
   - Writes identical copy to legacy mirror `workerSiteMap/{siteId}`.
   - Removes transferred workers from previous sites in the same atomic commit.
2. Attendance Submission:
   - Writes daily log to `workersAttendance/{attendanceDocId}`.
   - Iterates over all mapped workers and updates individual `WorkerMonthlyAttendance/{workerId}_{month}`.
   - Commits atomically in a single batch.

```typescript
  // ===========================================================================

  static async getNextLabourId(orgId: string): Promise<string> {
    try {
      const q = query(
        this.getOrgCol(orgId, 'labours'),
        orderBy('labourId', 'desc'),
        limit(1)
      );
      const snap = await getDocs(q);
      if (snap.empty) return 'LT001';

      const lastId = snap.docs[0].data().labourId || 'LT000';
      const numPart = parseInt(lastId.replace(/\D/g, ''), 10) || 0;
      return `LT${String(numPart + 1).padStart(3, '0')}`;
    } catch {
      return 'LT001';
    }
  }

  static async getLabourTrades(orgId: string): Promise<LabourTrade[]> {
    const q = query(this.getOrgCol(orgId, 'labours'), orderBy('designation', 'asc'));
    const snap = await getDocs(q);
    return snap.docs.map(d => ({ ...(d.data() as LabourTrade), labourId: d.id }));
  }

  static async createLabourTrade(
    orgId: string,
    trade: { designation: string; salary: number | string }
  ): Promise<string> {
    const cleanDesignation = trade.designation.trim();
    // Verify duplicate designation
    const dupQ = query(
      this.getOrgCol(orgId, 'labours'),
      where('designation', '==', cleanDesignation)
    );
    const dupSnap = await getDocs(dupQ);
    if (!dupSnap.empty) {
      throw new Error(`Trade designation "${cleanDesignation}" already exists.`);
    }

    const labourId = await this.getNextLabourId(orgId);
    const docRef = doc(db, 'organisation', orgId, 'labours', labourId);
    await setDoc(docRef, {
      labourId,
      designation: cleanDesignation,
      salary: trade.salary.toString(),
      createdAt: serverTimestamp(),
      updatedAt: serverTimestamp()
    });
    return labourId;
  }

  static async saveSiteWorkerMapping(
    orgId: string,
    siteId: string,
    siteName: string,
    supervisor: string,
    workersList: MappedWorkerItem[]
  ): Promise<void> {
    const batch = writeBatch(db);
    const cleanSiteId = siteId.trim();
    const cleanSiteName = siteName.trim();
    const combinedKey = `${cleanSiteId}_${cleanSiteName}`;

    const docData: SiteWorkerMapping = {
      site: cleanSiteId,
      siteId: cleanSiteId,
      siteName: cleanSiteName,
      projectName: cleanSiteName,
      supervisor: supervisor || 'Unassigned',
      totalWorkersMapped: workersList.length,
      workers: workersList,
      updatedAt: serverTimestamp()
    };

    // 1. Commit mapping to canonical keys across workerSiteMapping & legacy workerSiteMap
    const targetKeys = [cleanSiteId, cleanSiteName, combinedKey];
    for (const key of targetKeys) {
      const ref1 = doc(db, 'organisation', orgId, 'workerSiteMapping', key);
      const ref2 = doc(db, 'organisation', orgId, 'workerSiteMap', key);
      batch.set(ref1, docData, { merge: true });
      batch.set(ref2, docData, { merge: true });
    }

    // 2. Clean up transferred workers from all other sites
    const addedIds = new Set(workersList.map(w => w.workerId.toLowerCase()).filter(Boolean));
    const otherDocsSnap = await getDocs(this.getOrgCol(orgId, 'workerSiteMapping'));

    for (const otherDoc of otherDocsSnap.docs) {
      if (targetKeys.includes(otherDoc.id.trim())) continue;
      const data = otherDoc.data();
      const rawWorkers: any[] = data.workers || [];
      let modified = false;

      const filtered = rawWorkers.filter(w => {
        const id = (w.workerId || w.id || '').toString().toLowerCase();
        if (id && addedIds.has(id)) {
          modified = true;
          return false; // Remove transferred worker
        }
        return true;
      });

      if (modified) {
        batch.update(otherDoc.ref, {
          workers: filtered,
          totalWorkersMapped: filtered.length,
          updatedAt: serverTimestamp()
        });
      }
    }

    await batch.commit();
  }

    const audit = this.createAuditEntry(
      '3. Organization Authorization',
      'Rejected by Organization',
      'Organization',
      orgUserName,
      '',
      reason
    );

    const docRef = doc(db, 'organisation', orgId, 'siteSupervisorProjectStageSchedule', docId);
    await updateDoc(docRef, {
      status: 'rejected_by_org',
      statusDisplay: 'Rejected by Organization',
      currentStep: -1,
      rejectionReason: reason,
      rejectedBy: orgUserName,
      rejectedRole: 'Organization',
      approvalHistory: arrayUnion(audit),
      updatedAt: serverTimestamp()
    });
  }

  // Stage 3 -> 4: Manager final clearance & dispatch
  static async managerFinalClearance(
    orgId: string,
    docId: string,
    managerName: string,
    managerId: string,
    remarks: string
  ): Promise<void> {
    const audit = this.createAuditEntry(
      '4. Manager Final Clearance',
      'Final Approval & Release Completed',
      'Manager',
      managerName,
      managerId,
      remarks || 'Final clearance granted. Dispatched to site.'
    );

    const docRef = doc(db, 'organisation', orgId, 'siteSupervisorProjectStageSchedule', docId);
    await updateDoc(docRef, {
      status: 'approved',
      statusDisplay: 'Approved & Released',
      currentStep: 4,
      finalApprovedBy: managerName,
      finalClearanceRemarks: remarks,
      approvalHistory: arrayUnion(audit),
      updatedAt: serverTimestamp()
    });
  }

  // ===========================================================================
  // 5. DAILY ATTENDANCE & PAYROLL RECALCULATION
  // ===========================================================================

  static async submitDailyAttendance(
    orgId: string,
    siteId: string,
    siteName: string,
    supervisorName: string,
    supervisorId: string,
    workersAttendance: Record<string, DailyAttendanceRecord>,
    extraWorkers: any[] = []
  ): Promise<void> {
    const batch = writeBatch(db);
    const now = new Date();
    const todayDate = now.toISOString().split('T')[0]; // yyyy-MM-dd
    const currentMonth = `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, '0')}`; // yyyy-MM
    const currentDay = String(now.getDate()).padStart(2, '0');
    const formattedDate = `${currentDay}/${String(now.getMonth() + 1).padStart(2, '0')}/${now.getFullYear()}`;

    // 1. Update individual monthly attendance records
    let mappedPresentCount = 0;
    const workerEntries = Object.values(workersAttendance);

    for (const record of workerEntries) {
      const statusLower = record.attendance.toLowerCase();
      if (statusLower === 'present' || statusLower === 'overtime' || statusLower === 'half day') {
        mappedPresentCount += 1;
      }

      const monthlyDocId = `${record.workerId}_${currentMonth}`;
      const monthlyDocRef = doc(db, 'organisation', orgId, 'WorkerMonthlyAttendance', monthlyDocId);

      const dailyEntry = {
        status: statusLower,
        markedAt: serverTimestamp(),
        salaryPerDay: parseFloat(record.salary) || 0.0
      };

      batch.set(
        monthlyDocRef,
        {
          workerId: record.workerId,
          workerName: record.workerName,
          designation: record.designation,
          site: siteName,
          siteId: siteId,
          month: currentMonth,
          baseSalary: record.salary,
          status: 'verified',
          [`attendanceData.${todayDate}`]: dailyEntry
        },
        { merge: true }
      );
    }

    // 2. Prepare comprehensive site daily attendance document
    const cleanSiteId = siteId.trim().replace(/\s+/g, '_');
    const cleanSiteName = siteName.trim().replace(/\s+/g, '_');
    const cleanSupName = supervisorName.trim().replace(/\s+/g, '_');
    const attendanceDocId = `${cleanSiteId}_${cleanSiteName}_${cleanSupName}`;

    const attendanceDocRef = doc(db, 'organisation', orgId, 'workersAttendance', attendanceDocId);

    batch.set(
      attendanceDocRef,
      {
        day: currentDay,
        month: `${String(now.getMonth() + 1).padStart(2, '0')}-${now.getFullYear()}`,
        site: siteName,
        siteId: siteId,
        siteName: siteName,
        supervisor: supervisorName,
        supervisorId: supervisorId,
        workers: workersAttendance,
        extraWorkers: extraWorkers,
        totalMappedWorkers: workerEntries.length,
        totalMappedPresent: mappedPresentCount,
        totalExtraWorkers: extraWorkers.reduce((acc, curr) => acc + (curr.count || 0), 0),
        totalWorkersOnSite: mappedPresentCount,
        Day: formattedDate,
        date: formattedDate,
        updatedAt: serverTimestamp()
      },
      { merge: true }
    );

    await batch.commit();

    // 3. Recalculate monthly salaries
    await this.recalculateMonthlySalaries(orgId, siteId, currentMonth);
  }

  static async recalculateMonthlySalaries(
    orgId: string,
    siteId: string,
    month: string
  ): Promise<void> {
    const q = query(
      this.getOrgCol(orgId, 'WorkerMonthlyAttendance'),
      where('month', '==', month),
      where('siteId', '==', siteId)
    );

    const snap = await getDocs(q);
    const batch = writeBatch(db);

    for (const d of snap.docs) {
      const data = d.data();
      const attendanceMap = data.attendanceData || {};
      let totalSalary = 0.0;
      let presentDays = 0;

      Object.values(attendanceMap).forEach((details: any) => {
        if (!details) return;
        const status = (details.status || '').toLowerCase();
        const salaryPerDay = parseFloat(details.salaryPerDay) || 0.0;

        if (status === 'present' || status === 'overtime') {
          totalSalary += salaryPerDay;
          presentDays += 1;
        } else if (status === 'half day') {
          totalSalary += salaryPerDay / 2.0;
          presentDays += 1;
        }
      });

      batch.update(d.ref, {
        calculatedSalary: totalSalary,
        totalPresentDays: presentDays,
        updatedAt: serverTimestamp()
      });
    }

    await batch.commit();
  }
}
```
