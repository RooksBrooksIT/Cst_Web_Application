1. ARCHITECTURE & MULTI-TENANT FIRESTORE PATH PATTERN
----------------------------------------------------------------------------------------------------
All collections in the Organization module operate within a multi-tenant namespace:
Root Path: /organisation/{orgId}/{collectionName}

Where:
- {orgId} : The dynamic ID of the active organization (e.g. cst_xxxx or orgId from SharedPreferences)
- FirestoreService.getCollection(collectionName) automatically maps requests to:
  FirebaseFirestore.instance.collection('organisation').doc(orgId).collection(collectionName)
- Note on Sites: 'Site' and 'sites' collection queries are redirected to 'projects' as the canonical source.

3. FIRESTORE COLLECTIONS & FIELD MAPPINGS FOR OrgFinancePage
====================================================================================================

----------------------------------------------------------------------------------------------------
COLLECTION 1: 'projects' (or legacy 'Site')
Path: /organisation/{orgId}/projects
Document ID: {siteId}
----------------------------------------------------------------------------------------------------
Frontend Field / Value         | Firestore Document Field Names (with Fallbacks)
-------------------------------+--------------------------------------------------------------------
Site Identifier                | 'siteId' | 'siteid' | doc.id
Site Display Name              | 'siteName' | 'sitename' | 'projectName' | {siteId}
Project Name                   | 'projectName' | 'sitename' | 'siteName'
Client / Owner Name            | 'ownerName' | 'ownername' | 'clientName'
Client Phone Number            | 'ownerPhoneNumber' | 'ownerPhone' | 'phone'
Project Category               | 'projectCategory' (Default: 'House')
Project Sub-Category           | 'projectSubCategory' (Default: '2BHK')
Current Project Status         | 'currentStatus' | 'status' (Default: 'OnProgress' / 'Live')
Project Budget (Estimated)     | 'projectBudget' | 'budget'
Amount Paid / Income Received  | 'amountPaid' | 'paid' | 'amountReceived'
Amount Spent / Expenses        | 'amountSpent' | 'amountSpend' | 'spent' | 'totalAllExpenses'
Balance Remaining              | 'amountBalance' | 'balance'

----------------------------------------------------------------------------------------------------
COLLECTION 2: 'siteSupervisorMap'
Path: /organisation/{orgId}/siteSupervisorMap
Document ID: {siteId} or generated docId
----------------------------------------------------------------------------------------------------
Frontend Field / Value         | Firestore Document Field Names
-------------------------------+--------------------------------------------------------------------
Site ID Reference              | 'siteId' | 'siteid' | doc.id
Supervisor Assigned Name       | 'supervisorName' | 'supervisor' | 'name'

----------------------------------------------------------------------------------------------------
COLLECTION 3: 'totalSiteExpensesPerDay' (Real-time Aggregated Financial Totals)
Path: /organisation/{orgId}/totalSiteExpensesPerDay
Document ID: {canonicalSiteDocId} or {siteId}
----------------------------------------------------------------------------------------------------
Frontend Field / Value         | Firestore Document Field Names
-------------------------------+--------------------------------------------------------------------
Site Identifier Match          | 'siteId' | doc.id
Site Name Match                | 'siteName' | 'projectName'
Total Consolidated Expenses    | 'totalAllExpenses'
Supervisor / Daily Site Exp    | 'totalSiteExpense' | 'totalSupervisorExpense'
Manager Expenses Total         | 'totalMgrExpense'
Organization Expenses Total    | 'totalOrgExpense'
Contractor Payments Total      | 'totalContractorExpense'
Incentives Total               | 'totalIncentiveExpenses'
Petty Cash Received Total      | 'totalPettyCashReceived'
Petty Cash Spent Total         | 'totalPettyCashExpense'
Petty Cash Balance             | 'remainingPettyCash'

* Expense Calculation Fallback Logic:
  If 'totalAllExpenses' is present:
    totalExpenses = totalAllExpenses
  Else:
    totalExpenses = totalSiteExpense + totalMgrExpense + totalOrgExpense + totalContractorExpense + totalIncentiveExpenses

* Balance Calculation Logic:
  If budget > 0:
    amountBalance = budget - totalExpenses
  Else:
    amountBalance = amountPaid - totalExpenses

4. SITE FINANCIAL DETAILS DRILL-DOWN PAGE (SiteFinancialDetailsPage)
====================================================================================================
When a user clicks on any Site Card from the Finance Page, they are navigated to the detailed 
financial drill-down screen.

----------------------------------------------------------------------------------------------------
A. HEADER & KPI SUMMARY UI ELEMENTS
----------------------------------------------------------------------------------------------------
UI Elements & Values Displayed:
  [UI-D1] App Bar:
          - Title: "Site Financial Details"
          - Subtitle: "{siteName} ({siteId})"
          - Action: PDF Export Button ("Export Financial Statement")
  [UI-D2] Site Info Header Card:
          - Project & Site Name, Site ID, Status Badge
          - Category Tag (`{category} • {subCategory}`)
          - Owner Tag (`{ownerName} ({ownerPhone})`)
          - Location Tag (`{siteLocation}`)
          - Project Dates (`{startDate} → {endDate}`)
  [UI-D3] Financial Summary KPI 2x2 Matrix:
          1. "Estimated Budget"      : ₹ {Formatted Budget}
          2. "Customer Received"     : ₹ {Formatted Received}
          3. "Expenses Spent"        : ₹ {Formatted Spent}
          4. "Balance from Received" : ₹ {Formatted Cash in Hand} (Received - Spent)
  [UI-D4] Budget Remaining Banner:
          - Label: "Budget Remaining (Budget - Spent):"
          - Amount: ₹ {Formatted Remaining}
  [UI-D5] Budget Utilization Progress Bar & Percentage:
          - Visual Bar + Text: "{usagePercent}%"
  [UI-D6] Site Petty Cash Summary Card:
          - Badge: "Active" / "Overspent"
          - Received Mini Stat  : ₹ {Formatted Petty Cash Received}
          - Spent Mini Stat     : ₹ {Formatted Petty Cash Spent}
          - Remaining Mini Stat : ₹ {Formatted Petty Cash Remaining}
  [UI-D7] Quick Action CTA Buttons:
          - [Petty Cash Hub]   -> Navigates to OrgPettyCashPage
          - [Record Expense]   -> Navigates to OrganizationExpenses
  [UI-D8] 3 Main Tabs:
          - Tab 1: [Summary]
          - Tab 2: [Client Income]
          - Tab 3: [Expenses]

----------------------------------------------------------------------------------------------------
B. TAB 1: SUMMARY (Category Distribution & Performance)
----------------------------------------------------------------------------------------------------
UI Elements & Values Displayed:
  [UI-D9]  Expense Category Distribution List:
           - "Site & Daily Supervisor Entries" : ₹ {totalSupervisorExpense}
           - "Site Petty Cash Expenses"        : ₹ {totalPettyCashExpense}
           - "Manager Expenses"                : ₹ {totalMgrExpense}
           - "Organization Expenses"           : ₹ {totalOrgExpense}
           - "Contractor Payments"             : ₹ {totalContractorExpense}
           - "Incentives & Extra"              : ₹ {totalIncentiveExpenses}

  [UI-D10] Financial Performance Indicators:
           - Payment Realization : {((received / budget) * 100)}% (Client paid vs Total Contract)
           - Cost Efficiency     : {(((budget - spent) / budget) * 100)}% (Remaining margin cushion)
           - Cash Flow Health    : Positive / Negative (+/- ₹ {received - spent})

----------------------------------------------------------------------------------------------------
C. TAB 2: CLIENT INCOME (Milestones & Inflows)
----------------------------------------------------------------------------------------------------
UI Elements & Values Displayed:
  [UI-D11] Total Income Received Summary Banner: ₹ {totalReceived}
  [UI-D12] Individual Client Payment Cards List:
           - Payment Stage / Note / Description
           - Payment Date (Formatted: dd MMM yyyy)
           - Payment Amount (+ ₹ {amount})

Firestore Collection: 'SitePayment'
Path: /organisation/{orgId}/SitePayment
Query: .where('siteId', isEqualTo: siteId)
Fields Used:
  - 'siteId'        : Matches the active site
  - 'amount'        : Payment amount ('amount' | 'paymentAmount')
  - 'paymentDate'   : Payment timestamp ('paymentDate' | 'date' | 'createdAt')
  - 'notes'         : Description / stage name ('notes' | 'description' | 'stageName')

----------------------------------------------------------------------------------------------------
D. TAB 3: ITEMIZED EXPENSES (Comprehensive Granular Outflows)
----------------------------------------------------------------------------------------------------
UI Elements & Values Displayed:
  [UI-D13] Chronological Expense Item Cards (Newest to Oldest):
           - Icon: Red upward arrow (General) or Orange wallet (Petty Cash)
           - Expense Title / Description / Stage / Material / Bill #
           - Date: Formatted date (dd MMM yyyy)
           - Vendor / Supplier / Recipient Name
           - Category Badge: Supervisor / Manager / Organization / Contractor / Incentive / Petty Cash
           - Expense Amount (- ₹ {amount})

Firestore Collections Queried for Tab 3:
----------------------------------------------------------------------------------------------------
1. 'siteSupervisorEntries' : Daily site supervisor logs (labour, materials, food, transport, fuel)
   Fields: 'siteId', 'siteName', 'expenseType', 'category', 'materialName', 'projectStage', 
           'totalAmount', 'amount', 'date', 'createdAt', 'vendorName', 'supplier', 'labours', 'materials'
2. 'pettyCashTransactions' : Site petty cash transactions
   Fields: 'siteId', 'description', 'expenseCategory', 'amount', 'transactionDate', 'createdAt', 'vendorName'
3. 'organizationEntries'   : Central organization bills and vouchers
   Fields: 'siteId', 'projectStage', 'expenseName', 'description', 'totalAmount', 'bills' (billNo, billAmount, billDate, billVendor)
4. 'managerEntries'        : Site manager approved expenses
   Fields: 'siteId', 'expenseType', 'category', 'totalAmount', 'date', 'vendorName', 'supplier'
5. 'contractorEntries'     : Direct payments to contractors
   Fields: 'siteId', 'contractorName', 'category', 'totalAmount', 'date', 'createdAt'
6. 'siteSupervisorIncentives' : Supervisor milestone/performance incentives
   Fields: 'siteId', 'supervisorName', 'role', 'incentiveAmount', 'amount', 'date'
