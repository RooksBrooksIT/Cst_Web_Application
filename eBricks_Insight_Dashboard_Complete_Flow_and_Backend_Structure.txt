1. EXECUTIVE OVERVIEW & NAVIGATION ARCHITECTURE
--------------------------------------------------------------------------------

The eBricks Insight Dashboard system is a multi-page analytics hub providing 
executive-level, site-level, financial, stage-wise, contractor, and petty cash 
insights. All analytics query Firestore in real time using multi-tenant organization 
isolation (/organisation/{orgId}/data/{collection}).

Role-Based Access:
  - Organization Admin / HQ  : Full access to all 6 sub-dashboards across all sites/projects.
  - Manager                  : Access to assigned projects, stage insights, and expenses.
  - Supervisor               : Read-only access to assigned site reports.

Navigation Hierarchy & User Flow:
  [Insights Dashboard Main Hub] (insights_dashboard.dart)
     |-- 1. Site/Project Expenses Report (organization_insights_screen.dart)
     |-- 2. Site/Project Stage Expenses (project_stage_insights_dashboard.dart)
     |-- 3. Site/Project Status Report (site_status_report.dart)
     |-- 4. Financial Status Report (project_financial_status_report_page.dart)
     |-- 5. Contractor Report (contractor_report_page.dart)
     +-- 6. Petty Cash Expenses Insights (organization_petty_cash_insights_screen.dart)

--------------------------------------------------------------------------------
2. DASHBOARD PAGE 1: INSIGHTS DASHBOARD HUB
--------------------------------------------------------------------------------
Route/Page: /insights (insights_dashboard.dart)
Purpose: Central portal displaying summary tiles for all analytics sub-dashboards.

Displayed Cards & User Interactions:
  - Card 1: Site/Project Expenses Report -> Navigates to /insights/expenses
  - Card 2: Site/Project Stage Expenses  -> Navigates to /insights/stage-expenses
  - Card 3: Site/Project Status Report   -> Navigates to /insights/site-status
  - Card 4: Financial Status Report      -> Navigates to /insights/financial-status
  - Card 5: Contractor Report            -> Navigates to /insights/contractors
  - Card 6: Petty Cash Expenses Insights -> Navigates to /insights/petty-cash

--------------------------------------------------------------------------------
3. DASHBOARD PAGE 2: SITE/PROJECT EXPENSES REPORT
--------------------------------------------------------------------------------
Route/Page: /insights/expenses (organization_insights_screen.dart)
Purpose: Real-time tracking of site-level daily expenses, date-range spending, and site summaries.

Sub-Modes & Navigation:
  - Mode A: Daily Expense Mode (Filter by single date) -> Launches DailySiteReportScreen
  - Mode B: Expense Range Mode (Filter by From & To Date) -> Launches SiteExpensesReportPage
  - Mode C: Site Summary Mode (Filter by Site ID) -> Launches SiteSummaryPage

Primary Collections Used:
  - /organisation/{orgId}/data/siteSupervisorEntries
  - /organisation/{orgId}/data/totalSiteExpensesPerDay
  - /organisation/{orgId}/data/projects

KPI Cards & Summary Indicators:
  - Total Expense Amount (₹) = Sum of amount/totalamount across filtered entries
  - Active Expense Sites Count = Count of unique siteIds with expense records
  - Average Daily Spending (₹) = Total Expense Amount / Filtered Days Count

Filter Controls & Query Logic:
  - Site Selector Dropdown: Defaults to "All Sites". Filter: siteId == selectedSiteId
  - Date Picker           : Filter: date >= fromDate AND date <= toDate

--------------------------------------------------------------------------------
4. DASHBOARD PAGE 3: SITE/PROJECT STAGE EXPENSES DASHBOARD
--------------------------------------------------------------------------------
Route/Page: /insights/stage-expenses (project_stage_insights_dashboard.dart)
Purpose: Stage-by-stage construction expense tracking (Foundation, Framing, Plastering, Electrical, Finishing).

Primary Collections Used:
  - /organisation/{orgId}/data/siteSupervisorProjectStageSchedule
  - /organisation/{orgId}/data/stageProgress
  - /organisation/{orgId}/data/projects
  - /organisation/{orgId}/data/siteSupervisorEntries

KPI Cards & Stage Breakdown Table:
  - Active Stage Name (e.g. "Structure & Framing")
  - Stage Completion Percentage (%) = (Completed Stage Days / Total Stage Days) * 100
  - Stage Estimated Budget (₹) vs Actual Stage Expenditure (₹)
  - Stage Variance (₹) = Stage Estimated Budget - Actual Stage Expenditure
  - Schedule Alert Indicator:
      - "On Schedule" (Green)
      - "Near Completion" (Blue)
      - "Overdue / Delayed by X Days" (Red Alert)

Stage Data Aggregation Logic:
  Group siteSupervisorEntries by projectStage field (e.g., "Foundation", "Plastering").
  Sum amount for each stage and compare against stage budget in siteSupervisorProjectStageSchedule.

--------------------------------------------------------------------------------
5. DASHBOARD PAGE 4: SITE/PROJECT STATUS REPORT
--------------------------------------------------------------------------------
Route/Page: /insights/site-status (site_status_report.dart & site_status_report_page.dart)
Purpose: High-level site health dashboard displaying status badges, progress bars, and spending ratios.

Primary Collections Used:
  - /organisation/{orgId}/data/projects
  - /organisation/{orgId}/data/totalSiteExpensesPerDay
  - /organisation/{orgId}/data/siteMaterialsRequest
  - /organisation/{orgId}/data/siteToolsRequest
  - /organisation/{orgId}/data/workersAttendance

KPI Cards & Status Pills:
  - Total Active Sites Count
  - Total Completed Sites Count
  - Total Overdue / Delayed Sites Count
  - Total Budget Allocated across Sites (₹)
  - Overall Spending Percentage (%) = (Total Spent / Total Budget) * 100

Status Pill Threshold Rules:
  - "On Budget"      : Spent / Budget < 80% (Green)
  - "High Expense"   : Spent / Budget >= 80% and < 100% (Amber)
  - "Budget Exceeded": Spent / Budget >= 100% (Red)

--------------------------------------------------------------------------------
6. DASHBOARD PAGE 5: FINANCIAL STATUS REPORT
--------------------------------------------------------------------------------
Route/Page: /insights/financial-status (project_financial_status_report_page.dart & financial_status_report.dart)
Purpose: Financial health analysis comparing planned budget, customer received payments, and actual expenses.

Primary Collections Used:
  - /organisation/{orgId}/data/projects
  - /organisation/{orgId}/data/expenses
  - /organisation/{orgId}/data/totalSiteExpensesPerDay
  - /organisation/{orgId}/data/pettyCashRequests

Executive Summary KPIs:
  1. Total Estimated Budget (₹)  = Sum(projectBudget || estimatedBudget)
  2. Total Customer Received (₹) = Sum(amountReceived || amountPaid)
  3. Total Spent Expenses (₹)    = Sum(totalExpense || amountSpent)
  4. Net Cash Balance (₹)        = Total Customer Received - Total Spent Expenses
  5. Remaining Budget (₹)        = Total Estimated Budget - Total Spent Expenses
  6. Overall Budget Usage (%)    = (Total Spent Expenses / Total Estimated Budget) * 100

Financial Progress Bar & Chart Mappings:
  - Budget Utilization Bar: Spent (Red/Amber) vs Remaining (Teal)
  - Customer Payment Bar  : Received (Blue) vs Pending Customer Amount (Grey)

7. DASHBOARD PAGE 6: CONTRACTOR REPORT
--------------------------------------------------------------------------------
Route/Page: /insights/contractors (contractor_report_page.dart)
Purpose: Contractor-wise work execution, billings, and payment history.

Primary Collections Used:
  - /organisation/{orgId}/data/contractors
  - /organisation/{orgId}/data/contractorEntries
  - /organisation/{orgId}/data/projects

KPI Cards & Table Columns:
  - Total Registered Contractors
  - Total Contractor Work Bill Value (₹)
  - Total Paid to Contractors (₹)
  - Pending Contractor Balance (₹)
  - Table Columns: Contractor Name, Trade/Work Type, Site Name, Total Bill, Paid Amount, Balance.

--------------------------------------------------------------------------------
8. DASHBOARD PAGE 7: PETTY CASH EXPENSES INSIGHTS
--------------------------------------------------------------------------------
Route/Page: /insights/petty-cash (organization_petty_cash_insights_screen.dart)
Purpose: Tracking of cash distributions, supervisor petty cash requests, category expenses, and balances.

Primary Collections Used:
  - /organisation/{orgId}/data/pettyCashRequests
  - /organisation/{orgId}/data/expenses
  - /organisation/{orgId}/data/totalSiteExpensesPerDay

Summary KPIs & Financial Breakdown:
  1. Total Petty Cash Approved (₹) = Sum(amount) where status == "APPROVED" || "COMPLETED"
  2. Total Petty Cash Spent (₹)    = Sum(spentAmount)
  3. Remaining Petty Cash (₹)      = Total Approved - Total Spent
  4. Category Breakdown (Pie Chart / Bar List):
       - Material Expenses (Cement, Steel, Bricks, Sand)
       - Fuel & Vehicle Rentals
       - Site Labour & Food Expenses
       - Admin & Miscellaneous

10. FRONTEND WEB IMPLEMENTATION GUIDE (REACT / JS)
--------------------------------------------------------------------------------

Step A: Create Analytics API Service (services/insightService.js)
  - fetchFinancialStatusReport(orgId, siteId, dateRange)
  - fetchStageExpensesReport(orgId, siteId)
  - fetchSiteStatusSummary(orgId)
  - fetchPettyCashInsights(orgId, timeFilter, siteId)
  - fetchContractorReport(orgId)

Step B: Standard Null & Zero Handling:
  - If projectBudget == null or 0 -> Safely fallback to 0.0, display "N/A" or "₹0"
  - Ratio calculation: ratio = budget > 0 ? (spent / budget) : 0.0
  - Date parsing: Use try-parse for Timestamp, ISO string, or dd-MM-yyyy formats.

Step C: Export Functions:
  - Generate PDF Report via `jspdf` / `html2canvas`
  - Export CSV via `xlsx` or standard CSV string blob download.
